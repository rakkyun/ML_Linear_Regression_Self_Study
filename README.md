# Machine Learning Programs

A set of Jupyter notebooks covering the main regression topics from Unit 3 of the MCA Machine Learning syllabus.

## Notebook order
1. Simple Linear Regression from Scratch
2. Simple Linear Regression with scikit-learn
3. Multiple Linear Regression using the Normal Equation
4. Linear Regression with Gradient Descent
5. Polynomial Regression (extra regression exercise)
6. Linear Regression Evaluation and Visualization

## Datasets
The `datasets` folder contains the small datasets required by the notebooks. All notebooks use relative paths, so the project can be moved to another computer without editing Windows-specific paths.

## Packages
- numpy
- pandas
- matplotlib
- scikit-learn
- jupyter notebook

## Run
Open Jupyter in the project folder and run the notebooks from top to bottom.
